# Mirai – Personal Diary Application (Android)

Android application for creating and managing personal diary entries with local persistence and multimedia support.

## Tech stack
- Kotlin
- Jetpack Compose

## Key features
- Creation and storage of diary entries with timestamps and metadata
- Support for multimedia attachments (images and voice recordings)
- Multiple views for browsing entries, including list and calendar formats
- Local data persistence and media compression
- User customization options (themes, font size, profile settings)

## Project context
Developed by a team of three students as part of a university project. The application is prepared for distribution via the Google Play Store.
